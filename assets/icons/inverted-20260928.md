# Inverted app icon

The user supplied a red/pink music-note raster icon and requested a color-inverted
app icon while preserving the existing logo files. Edited with the built-in
imagegen tool (not the API/CLI). This is a generated edit, not a pixel-exact
computed negative.

Selected source: `icon-source-inverted-20260928.png`.
The existing `icon-source-20260709.png` and all original public icons are retained.

Exports in `public/assets/icons/`:

- `icon-192-inverted-20260928.png`: 192 × 192
- `icon-512-inverted-20260928.png`: 512 × 512
- `icon-maskable-512-inverted-20260928.png`: 512 × 512, 26 px inset for OS masks
- `apple-touch-icon-inverted-20260928.png`: 180 × 180

Exports use bicubic downsampling. The selected source is opaque: exterior
corners are cyan, avoiding a rendered checkerboard in installed icons.

## Prompt sequence

1. Use case: precise-object-edit
   Asset type: app icon
   Input images: Image 1 is the edit target, the user's attached red/pink rounded-square music-note icon.
   Primary request: Invert ONLY the colors of this exact image. Apply a photographic RGB negative: each R, G, B channel becomes 255 minus its original value. Red/pink becomes cyan/blue-green, and the white/pale pink music note becomes black/dark green. This is a strict color inversion, not a redesign or a palette swap.
   Constraints: Preserve the exact silhouette, music-note shape, position, proportions, rounded-square geometry, framing, edge detail, gradients and shading locations of the attached image. Preserve the original transparency/alpha at the outer corners; provide true transparency where the original is transparent. Do not add padding, text, extra symbols, objects, new shadows, or any other design changes. Output the single edited icon, square image.

2. Use case: background-extraction
   Asset type: app icon PNG with real alpha transparency
   Input image 1 is the edit target: the cyan color-inverted music-note app icon from the immediately preceding generation.
   Primary request: Remove ONLY the gray checkerboard pixels outside the rounded-square icon. Make these exterior corners genuinely transparent in the PNG alpha channel (alpha=0), NOT a drawn checkerboard. Keep ALL pixels of the cyan rounded-square icon and dark music note visually unchanged, including shape, proportions, position, gradients, edges, embossed details and framing. Preserve the exact existing cyan/dark color-inverted design. Do not redraw or redesign the icon, do not shift or resize its content, do not add padding or text. The result must be one square icon image with actual transparent outer corners, no visible gray checkered pattern and no opaque background.

3. Use case: precise-object-edit
   Asset type: opaque, full-bleed app icon PNG
   Input image 1 is the edit target: the cyan inverted music-note icon.
   Primary request: Replace ONLY the tiny gray/white checkerboard areas in the four outer corners with solid cyan #00dfe3 matching the icon background. The delivered PNG must be an entirely opaque square with NO checkerboard and NO transparency. Keep the existing rounded icon and its music-note symbol exactly as they are; only fill the exterior checkerboard pixels. Keep all shape geometry, framing, dimensions, cyan gradient, dark music note, edge details and highlights unchanged. Do not move, crop, stretch, scale, redesign, relight or add anything. No text. This is preparation of the existing inverted-color icon for an OS to apply its own rounded app-icon mask.
